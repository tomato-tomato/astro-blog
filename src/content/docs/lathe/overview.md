如果你让 AI 写过技术教程，大概遇到过这几件事：第一版读起来很顺，照着敲却跑不通；写到第三部分时，前面用过的例子和数字全变了；换一个会话，AI 完全不记得这门课讲到哪；想复习时，只能把十几篇 markdown 从头再读一遍。

**Lathe 就是为了解决这些问题而做的一套技能（Agent Skill）**：它不是「提示词模板」，而是一组写进技能文件的协议——规定 AI 怎么研究主题、怎么锁定版本、怎么保持前后一致、怎么把教程落到磁盘上、以及怎么在后续操作里复用这些状态。

一句话概括：**你只管提主题和继续学，剩下的结构、一致性和文件管理由技能负责。**

## 它能做到什么

| 你担心的事                               | Lathe 的处理方式                                                                                       |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 内容凭记忆编，跑不通                     | 生成前强制做网络研究（官方文档、论文、源码），关键事实旁附来源；没有网络工具时明确标记 `[!UNVERIFIED]` |
| 版本漂移，示例用到了锁定版本里没有的特性 | 生成时锁定工具链版本，并做「版本-特性一致性检查」；验证阶段还会静态预检                                |
| 教程前后不连贯，例子换来换去             | 用「控制性示例」贯穿全课，固定数字、隐喻、已讲概念都记在连续性摘要里                                   |
| 每次续写都要重读全部历史，又贵又慢       | 续写只读 `metadata.json` 的连续性摘要 + 最后一个部分，历史部分不重读                                   |
| 学完就散，没法复习                       | `/lathe 复习` 生成结构化复习材料；`/lathe 面试` 生成按 Part 分章的面试要点文档                         |
| 教程文件不知道放哪、有多少门课不清楚     | 统一登记在 `~/.lathe/config.json`，`/lathe 列表` 按语言分组列出全部课程与验证状态                      |

## 一条命令，十个操作

所有操作都通过 `/lathe` 调用，后跟**意图关键词**（中文或英文均可）和参数：

| 操作         | 命令                                      | 功能                                                           | 写入文件                                      |
| ------------ | ----------------------------------------- | -------------------------------------------------------------- | --------------------------------------------- |
| **生成教程** | `/lathe <主题>`                           | 生成教程的第一部分                                             | `part-01.md`、`metadata.json`、登记位置       |
| **续写教程** | `/lathe 续写\|extend <slug> [指导]`       | 为已有教程添加下一部分（该教程已有面试文档时会自动同步本部分） | `part-NN.md`、更新 `metadata.json`            |
| **收尾完结** | `/lathe 续写 收尾 <slug>`                 | 生成总结部分并完结课程                                         | 总结 `part-NN.md`、更新 `metadata.json`       |
| **复习教程** | `/lathe 复习\|review <slug>`              | 生成复习材料（不改变课程方向与状态）                           | `part-NN-review.md`                           |
| **面试文档** | `/lathe 面试\|interview <slug> [part-NN]` | 生成或补齐面试要点文档（一个 slug 一个文件，按 Part 分章）     | `<slug>.md` 或 `interview.md`                 |
| **验证教程** | `/lathe 验证\|verify <slug>`              | 端到端执行教程，含版本冲突检测与修复                           | `verify-result.json`、`.lathe-verify/` 工作区 |
| **提问内容** | `/lathe 提问\|ask <slug> [part] <问题>`   | 基于该教程的具体内容回答问题                                   | 无（只读）                                    |
| **管理标签** | `/lathe 标签\|tag <slug>`                 | 管理教程的搜索标签                                             | 更新 `metadata.json`                          |
| **创建语气** | `/lathe 语气\|voice [名称]`               | 创建自定义写作语气预设                                         | `voices/<名称>.md`                            |
| **扫描登记** | `/lathe 扫描\|scan [目录]`                | 把磁盘上未被识别的教程登记进来，并清理失效条目                 | 仅 `~/.lathe/config.json`                     |
| **列出教程** | `/lathe 列表\|list [slug]`                | 按语言分组列出所有教程，或查看某教程详情                       | 无（只读）                                    |

> 也支持纯自然语言触发（不写 `/lathe`），AI 会自己识别意图。意图不明确时不会瞎猜，而是给出选项菜单让你挑。

这里的 `slug` 是每门课的短标识（比如 `raft-go`、`digital-synth-zig`），生成时由 AI 从主题推导并经你确认——此后所有操作都靠它调用，它同时也是教程的目录名。

## 适合谁

- **在系统学一门语言或一个领域的人**：Rust、Zig、Go、分布式、编译器……想要的是「能跑通、有练习、有检查点」的连载课程，而不是一篇收藏了就再没打开的文章。
- **想按自己节奏推进的人**：一次只写一个部分，你可以跑完代码、做完练习再续写，也可以中途说「这部分实现日志复制」来指定方向。
- **需要把学过的东西转成面试表达的人**：`/lathe 面试` 会把教学要点重组成「一句话回答 → 展开 → 追问点 → 我的项目里」四层。
- **不适合的**：想要一篇 500 字速成答案的场景。Lathe 产出的是长课程，它的价值在于持续学习，不在于即时回答。

## 运行环境与版本

- 本指南对应技能版本 **v0.5.3**。版本号有三处可确认：`lathe/SKILL.md` 的 frontmatter `version:` 字段、正文顶部的「技能版本」行，以及 `/lathe 列表` 输出末尾的版本行；每门课 `metadata.json` 的 `lathe_version` 记录了生成或续写它时用的版本。
- 技能采用标准 Agent Skills 布局（`SKILL.md` 入口 + `references/` 子目录）。已在 **QoderWork** 与 **QoderWork CN** 桌面客户端上实测，并确认兼容 Reasonix 等支持该标准的终端 Agent；其他客户端请先小规模验证（详见[常见问题](/docs/lathe/faq/)）。
- 教程数据由 `~/.lathe/config.json` 管理，与具体客户端无关——在两个客户端之间切换时，教程、标签、验证结果完全共享。

> v0.5.3 起的几轮更新集中在三件事：新增面试文档；按「主题新颖度」自适应检索预算与讲解深度；续写与列表的加载精简（连续性摘要、`part_titles` 映射）。**都不需要迁移旧教程**，缺失字段会在下次写回时自动补齐。
